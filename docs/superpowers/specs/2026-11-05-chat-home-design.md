# 설계: 대화형 홈 (링크 검사를 채팅처럼)

상태: 설계 승인 (2026-11-05: "대화 모양 화면" + 구현 방식 A). 관련: `docs/plans/manual_url_check.md`(앱 안 검사), 메모리 "cloud only on user request".

## 0. 결정
- **대화 모양 화면**이다. 자유 대화 챗봇이 아니다. RedFlag의 말풍선은 모두 판정 결과(점수·근거)에서 만든 정해진 형식이다.
  "모델은 증인, 점수는 코드" 그대로이고, 붙여 넣은 글이 모델에게 명령하는 경로가 늘지 않는다.
- 구현 방식 A: 판정 카드·맥락 질문·정밀 분석 상태는 말풍선 안에, 상세 근거는 기존 분석 화면(`AnalysisScreen`)을 그대로 띄운다.
  검사 1건 = 기존 `AnalysisController` 1개(`inspect = true`). 분석 엔진은 바꾸지 않는다.

## 1. 화면
```
[◆ RedFlag        ● 보호 중   ⚙]   ← 보호 상태(탭 → 설정), 설정
 RedFlag: 링크나 받은 메시지를 붙여 넣어 주세요. 열기 전에 확인해 드려요.
 (보호 설정이 덜 됐으면) RedFlag: 보호를 켜려면 N단계가 남았어요 [설정]
 ── 지난 검사 ──  (최근 8건, 링크와 판정만. 탭 → 저장된 판정)
 ── 새 검사 ──
            [사용자 말풍선: 붙여 넣은 글]
 [판정 카드: 검사 중 단계 → 점수·한 줄 요약·근거 3개 · 자세히 / Chrome에서 열기 / 정밀 분석]
 [맥락 질문 카드 (해당할 때만)]
[📋][ 링크나 받은 메시지 …            ][➤]
```

## 2. 입력 해석 — `ChatRouter` (순수, 테스트)
| 입력 | 처리 |
|---|---|
| 링크 1개 | 검사. 링크를 뺀 나머지 글 = **받은 메시지**(`<untrusted_conversation>`, 지금 붙여넣기와 같음) |
| 링크 여러 개 | "링크가 N개 있어요" + 선택 칩 |
| 링크 없음, 마지막 검사가 있음 | 그 검사에 대한 **사용자 본인의 상황 설명**(`<user_statement>`) → `submitAnswer` → 다시 판정(점수는 더하기만) |
| 링크 없음, 검사 전 | "링크를 찾지 못했어요" |
- 정밀 분석은 카드의 버튼으로만 시작한다. 글로 "정밀 분석 해줘"라고 쳐도 보내지 않는다(`NoAutomaticCloudTest`).
- Chrome은 버튼으로만 연다. 앱이 스스로 Chrome을 열지 않는다(검사 결과가 안전이어도).

## 3. 저장
- 지난 검사는 기존 `ReportStore`(판정 보고서)에서 보여 준다. **붙여 넣은 원문과 상황 설명은 저장하지 않는다**(화면을 닫으면 사라진다).
- 앱을 처음 연 시점의 기록을 한 번만 읽는다(이번에 한 검사가 "지난 검사"에 중복으로 뜨지 않게).

## 4. 진입점
- 홈 = 대화 화면. 기존 카드(보호 설정, 통계, 분석 설정, 개발자, 개인정보)는 ⚙ **설정 화면**으로 옮긴다.
- 앱 바로가기 "링크 검사": 입력창에 포커스(클립보드는 읽지 않는다).
- **공유 / 텍스트 선택**: `ShareEntryActivity`가 공유된 글과 보낸 앱만 앱 프로세스 안의 `SharedInbox`에 넣고, 엑스트라 없이 홈을 연다.
  홈은 받은 글을 사용자 말풍선으로 넣고 바로 검사한다. 홈(MainActivity)은 외부에서 열 수 있으므로
  **인텐트 엑스트라로는 아무것도 받지 않는다**(외부 앱이 상황 설명·출발 앱을 꾸며 넣을 수 없다).
- 기록 탭 → 기존 `CheckActivity`(저장된 판정 + 다시 검사).

## 5. 테스트
- `ChatRouterTest`: 위 표의 모든 행, 디팽(`hxxps://evil[.]com`), 빈 입력.
- `InspectModeTest`: 클립보드는 [붙여넣기] 버튼에서만(파일 이름이 `ChatComposer.kt`로 바뀜, 규칙은 같음),
  Chrome은 버튼에서만(대화 화면 파일도 검사 대상에 추가), 공유는 `SharedInbox`에 글과 보낸 앱만 넣고 홈에는 엑스트라가 없다.
- 폰: 링크 붙여넣기 → 판정 카드, 링크 없는 글 → 상황 설명으로 재판정, 여러 링크 → 선택, 공유 → 대화에 들어와 검사.
